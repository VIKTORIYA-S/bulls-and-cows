# DESIGN

## Структуры данных и алгоритмы

### Состояние игры

- **Секрет** хранится строкой (`'0123'`, `'a3f1'`). Строка сохраняет лидирующие нули, а для сравнения её можно превратить в массив символов через `[...secret]`.
- **История попыток** — массив объектов `{ guess, bulls, cows }` (тип `GuessEntry` в `src/gameState.ts`). Массив подходит, потому что попытки идут в порядке добавления и их нужно показывать списком. Новая запись добавляется через `[...history, entry]` (`addGuess`), поэтому старый массив не меняется.
- **Настройки** — объект `{ length, base }`. Он не меняется во время раунда: при смене настроек создаётся новый объект (`{ ...settings, length }`).
- **Рекорды** — массив `RecordEntry` (`attempts`, `timeMs`, `length`, `base`), общий для всех настроек. Каждая запись показывается с подписью (бейджем) «N цифр, система». Список хранится в localStorage (`src/storage.ts`).

### evaluateGuess

1. Секрет и попытка приводятся к нижнему регистру и превращаются в массивы символов.
2. **Bulls** — число позиций, где символ попытки совпадает с символом секрета (`filter` по индексу).
3. **Общие цифры** — число символов попытки, которые есть в секрете (`filter` + `includes`). Цифры в секрете и попытке уникальны, поэтому считать дубли не нужно.
4. **Cows** = общие цифры − bulls: цифра угадана, но стоит не на своём месте.

### countPossibleSecrets

Число секретов — это число размещений без повторений: P(base, length) = base · (base − 1) · … · (base − length + 1). Рекурсивная формула: `permutations(length, base) = base * permutations(length - 1, base - 1)`, при `length === 0` результат 1. Если `length > base`, в произведении появляется множитель 0, и результат равен 0. Функция обёрнута в `memoize` (`Map` с ключом `JSON.stringify(args)`), поэтому повторный вызов с теми же аргументами (при каждом открытии настроек) берётся из кэша.

## Сложность

Обозначения: `n` — длина секрета (2–6), `b` — основание системы (2–16).

| Функция                | Сложность                                  | Обоснование                                                                                                                                    |
| ---------------------- | ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `generateSecret`       | O(n · b)                                   | Рекурсия `pickUnique` делает n шагов. На каждом шаге создаётся новая строка алфавита без выбранного символа (`slice`), это O(b).               |
| `evaluateGuess`        | O(n²)                                      | `filter` с `includes` внутри: для каждого из n символов попытки линейный поиск по n символам секрета. Подсчёт bulls — O(n).                    |
| `isValidGuess`         | O(n · b)                                   | Создание валидатора O(b). `every` проверяет n символов, каждая проверка — `includes` по алфавиту длиной b. `Set` для проверки повторов — O(n). |
| `countPossibleSecrets` | O(n) при первом вызове, O(1) при повторном | Рекурсия делает n умножений. Результат кэшируется, повторный вызов — поиск в `Map` по небольшому ключу.                                        |

Так как n ≤ 6 и b ≤ 16, на практике все функции работают за константное время. Оценки показывают, как они растут при увеличении параметров.

## Принципы чистого кода

- **Чистые функции без побочных эффектов.** `src/evaluateGuess.ts`, `src/isValidGuess.ts`, `src/gameState.ts`, `src/records.ts` только вычисляют результат по аргументам. `generateSecret` принимает `random` параметром, поэтому тестируется детерминированно.
- **Побочные эффекты вынесены на границу.** Работа с localStorage только в `src/storage.ts`, работа с DOM только в `src/main.ts`. Логика не зависит от браузера и тестируется без него.
- **Иммутабельность.** `addGuess` и `addRecord` возвращают новые массивы, а исходные не меняют (проверяется тестами).
- **Одна функция — одна задача.** `pickUnique` выбирает символы, `generateSecret` готовит алфавит, `memoize` отвечает только за кэш и не знает про перестановки (`src/countPossibleSecrets.ts`).
- **Понятные имена.** `isValidGuess`, `hasGuess`, `isWon` читаются как вопросы, `addGuess` и `addRecord` как действия.
- **Без магических значений.** Список систем счисления и длин вынесен в константы `BASES` и `LENGTHS` (`src/main.ts`), ключ хранилища в `KEY` (`src/storage.ts`).
- **Небольшие функции.** Каждая функция ядра занимает несколько строк и делает одно дело. UI разбит на `renderSettings`, `renderGame`, `renderWin`, `renderRecords`, `renderHistory`.
- **Тесты как документация.** Для каждой функции есть файл `*.test.ts` с названиями на русском, которые описывают поведение.
- **Известный недостаток (DRY).** Строка `'0123456789abcdef'` повторяется в `generateSecret.ts` и `createDigitValidator.ts`. Её можно вынести в общую константу.
